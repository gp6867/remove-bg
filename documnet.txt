# Deployment Guide

## Quick Deploy (5 minutes)

### Option 1: Docker (Recommended)
```bash
cd ai-image-platform
docker-compose up -d --build
```

### Option 2: Manual Deploy

#### Backend
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

#### Frontend
```bash
cd frontend
npm install
npm run build
npm start
```

## Deploy to VPS (DigitalOcean)

### 1. Create Droplet (Ubuntu 22.04)
- Size: 4GB RAM, 2 CPUs (minimum)
- Region: Mumbai/ Bangalore

### 2. Install Dependencies
```bash
sudo apt update
sudo apt install -y python3-pip postgresql nginx nodejs npm
```

### 3. Setup PostgreSQL
```bash
sudo -u postgres psql
CREATE DATABASE ai_image_db;
CREATE USER ai_user WITH PASSWORD 'strong_password';
GRANT ALL PRIVILEGES ON DATABASE ai_image_db TO ai_user;
```

### 4. Configure Nginx
```nginx
server {
    listen 80;
    server_name yourdomain.com;
    
    location / {
        proxy_pass http://localhost:5174;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
    }
    
    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
    }
}
```

### 5. Add SSL (Let's Encrypt)
```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com
```

## Environment Variables Setup

### Backend (.env)

### Frontend (.env.local)

NEXT_PUBLIC_API_URL=https://api.yourdomain.com

## Start Services

### Using Systemd (for production)

**Backend service:** `/etc/systemd/system/backend.service`
```ini
[Unit]
Description=AI Image Backend
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/ai-image-platform/backend
ExecStart=/home/ubuntu/ai-image-platform/venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

**Frontend service:** `/etc/systemd/system/frontend.service`
```ini
[Unit]
Description=AI Image Frontend
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/ai-image-platform/frontend
ExecStart=/usr/bin/npm start
Restart=always

[Install]
WantedBy=multi-user.target
```

### Start services
```bash
sudo systemctl daemon-reload
sudo systemctl enable backend frontend
sudo systemctl start backend frontend
```
